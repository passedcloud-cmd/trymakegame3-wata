# 지켜줄게요, 히나코

「나를 먹고 싶은, 괴물」의 **비공식 팬게임**이에요. (무료 배포)
뱀파이어 서바이벌 스타일의 2D 탑다운 액션 게임으로,
**인어 요괴 시오리가 되어, 뒤를 졸졸 따라오는 히나코를 식인 요괴들로부터 끝까지 지키는 게** 목표예요.
히나코의 체력이 0이 되면 실패!

## 실행 방법

설치할 건 없어요. **`index.html` 파일을 더블클릭**해서 브라우저(크롬 추천)로 열면 바로 시작돼요.

## 조작법

| 키 | 동작 |
| --- | --- |
| 방향키 | 이동 (히나코가 지나간 길을 따라와요) |
| Z (또는 왼쪽 Shift) | 손톱 공격 — 오른팔이 변형돼요. 누르고 있으면 계속 공격 |
| X (또는 A) | 파도 장벽 — 히나코 주변의 요괴를 날려 버리는 스킬 |
| Z / Enter / 마우스 클릭 | 대화 넘기기, 메뉴·레벨업 선택 |
| S (또는 오른쪽 위 「건너뛰기」 버튼) | 스토리 건너뛰기 |
| ESC (또는 P) | 일시정지 메뉴: 계속하기 / 메인화면으로 / 게임 종료 |
| M | 소리 켜기/끄기 |

## 게임 규칙

- 식인 요괴는 모두 **히나코를 노려요.** 시오리는 몸으로 요괴를 막을 수 있어요.
- 요괴를 쓰러뜨리면 파란 구슬(경험치)이 나와요. 모으면 레벨업 → 강화 3개 중 하나 선택.
- 가끔 나오는 하트를 시오리가 주우면 히나코의 체력이 회복돼요.
- 정해진 시간을 버티면 스테이지 클리어 → 일러스트와 대화로 스토리가 진행돼요.
- 3장에서는 보스(굶주린 대요괴)를 쓰러뜨려야 해요. 바닥이 빨갛게 빛나면 돌진 공격이 와요!
- 실패하면 그 스테이지 처음부터 다시 할 수 있어요.

| 요괴 | 특징 |
| --- | --- |
| 그림자 요괴 | 느리지만 많이 몰려와요 |
| 귀신불 | 빠르고 지그재그로 날아와요 |
| 오니 | 느리지만 튼튼하고 아파요 |
| 굶주린 대요괴 (보스) | 히나코를 향해 돌진하고 귀신불을 불러요 |

## 파일 구조 (어디를 고치면 되는지)

```
index.html        게임 페이지 (파일들을 불러오기만 해요)
css/style.css     화면 배경, 크기
js/input.js       키 배치  ← 조작키를 바꾸려면 KEYMAP 수정
js/sound.js       효과음 (코드로 만든 소리)
js/art.js         캐릭터·요괴·일러스트 그리기  ← 그림을 바꾸려면 여기
js/story.js       캐릭터 이름, 대사  ← 스토리를 바꾸려면 여기
js/data.js        스테이지, 요괴 체력/속도, 강화 목록  ← 난이도 조절은 여기
js/game.js        게임 규칙, 움직임, 화면 그리기 (게임의 심장)
```

### 자주 할 만한 수정

- **대사 바꾸기**: `js/story.js` 에서 `text` 부분만 고치면 돼요. 표정(`face`)은 `normal`, `smile`, `smirk`(능글맞은 미소), `sleepy`(졸린 눈), `worry`, `surprise`, `angry` 중에서 고를 수 있어요.
- **캐릭터 이름 바꾸기**: `js/story.js` 맨 위 `CHARACTERS` 의 `name`.
- **너무 어려워요/쉬워요**: `js/data.js` 에서
  - 스테이지 시간 `duration`, 요괴 등장 간격 `spawnEvery`
  - 요괴 공격력 `dmg`, 체력 `hp`
  - 히나코 체력 `followerMax`
- **스테이지 추가**: `js/data.js` 의 `STAGES` 에 항목을 하나 더 넣고, `js/story.js` 의 `STAGE_STORIES` 에도 대화를 하나 추가하세요.

### 직접 그린 그림으로 바꾸고 싶다면

지금 그림은 전부 코드(도형)로 그려져 있어서 이미지 파일이 없어요.
직접 그린 PNG를 쓰고 싶으면 `js/art.js` 의 `Art.portrait` 안에서
`ctx.drawImage(이미지, x, y, 너비, 높이)` 로 바꿔 주면 돼요. (필요하면 같이 해 보자!)
